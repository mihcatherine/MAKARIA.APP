## Adiantamento salarial
A configuração permite escolher **Sim** ou **Não** para adiantamento. Quando Sim, o usuário informa livremente o percentual. O valor do adiantamento é calculado como parte do mesmo salário e não como renda adicional.

## Ortografia
A interface usa português do Brasil com capitalização e acentuação revisadas.
